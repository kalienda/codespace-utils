# Codespace Utils
**Набор утилит для разработки мини-игр на JustMC**. Несмотря на изначальное предназначение для JustMC, 
некоторые инструменты мода могут работать и на других серверах в жанре Creative+.
## Установка и настройка
Самая актуальная версия мода работает на ядре Fabric, версия: 1.21.11. Убедитесь, что именно
эта технология установлена и правильно. **Процесс установки:**
1. Скачайте мод со страницы с релизами, вместе с [Fabric API](https://modrinth.com/mod/fabric-api) (необходимо);
2. Опционально, так же можно установить мод [Cloth Config API](https://modrinth.com/mod/cloth-config),
для удобной настройки поведения мода. Этот этап можно пропустить, если вы готовы редактировать файл
конфигурации мода вручную;
3. Перенесите мод в каталог с модификациями (по умолчанию это `~/.minecraft/mods/`, или 
`C:\Users\<имя пользователя>\AppData\Roaming\.minecraft\mods\` на Windows), и запустите игру;

После установки мода, подключитесь к JustMC, зайдите в мир, где у вас есть права разработчика, и перейдите в
мир кода (далее - "кодспейс"). <br>Отсюда, первое, что стоит настроить - это раскладку инвентаря.
### Система раскладок
Для этого, разложите предметы так, как вам удобно, после чего напишите команду `/arrangement create <название>`,
где `название` - любой текст, например, `my_arrangement`. После создания раскладки, откройте конфиг мода
(если у вас установлен Mod Menu, найдите Codespace Utils в списке, и откройте конфигурацию там, иначе
напишите команду `/csu config`). В категории "Инвентарь" найдите поле "Основная раскладка", и замените стандартный
файл на тот, что вы только что создали. Если размещение при входе в кодспейс включено, ваша раскладка будет
автоматически применена при входе туда.<br>
Вы можете создать несколько раскладок вышеупомянутой командой, и загружать их динамически в зависимости от
вашего желания командой `/arrangement load <название файла>`. Список раскладок можно посмотреть командой
`/arrangement list`.
### Передвижение в кодспейсе
Мод предоставляет возможность телепортироваться между этажами, если разрушить блок, из которого состоит
пол этажа кодспейса. Если блок находится выше игрока, он будет телепортирован на 7 блоков вверх, иначе -
на 7 блоков ниже. Вы можете выбрать способ телепортации - командой или отправкой пакета, настроить можно
в конфиге.<br>Мод также дает возможность выдать себе предмет для изменения скорости передвижения в кодспейсе,
он делает это автоматически при входе, если он включен и настроен.
